# Continente en llamas

Sitio web del juego de cartas de Ludens Docere sobre los procesos de independencia de América: presentación, cómo se juega, galería de las 61 cartas, uso en el aula y descargas print & play.

Un juego de Jorge Fonseca Leiva y Gustavo Godínez Vargas. Sitio estático (HTML + CSS + JS). Los datos de las cartas están en `data.json`.
